
# Ames Housing Data Analysis & Predictive Analytics

An end-to-end data analytics and machine learning project using the **Ames Housing Dataset**. This project covers data cleaning, exploratory data analysis (EDA), predictive modeling with Scikit-learn, and interactive dashboard visualization using Power BI.

---

##  Project Overview
The objective of this project is to analyze the factors influencing residential property prices in Ames, Iowa, and build machine learning models to predict housing prices accurately. The final insights and predictive outputs are visualized in a multi-page Power BI dashboard.

---

##  Tech Stack & Tools
* **Programming & Libraries:** Python, Pandas, NumPy, Seaborn, Matplotlib, Scikit-learn
* **Machine Learning:** Linear Regression, Logistic Regression / Classification workflows, Model Evaluation (MSE, RMSE, Confusion Matrix)
* **Business Intelligence:** Power BI (DAX, Power Query, Data Modeling)
* **Environment:** Google Colab

---

##  Key Features & Workflow

1. **Data Preprocessing & Cleaning:**
   * Handled missing values, outliers, and inconsistent categorical entries.
   * Engineered new features to improve predictive performance.
   * Saved clean data outputs for downstream modeling and visualization.

2. **Exploratory Data Analysis (EDA):**
   * Identified key correlations between house features (e.g., overall quality, square footage) and sale prices using **Seaborn** heatmaps and distribution plots.

3. **Machine Learning & Modeling:**
   * Built and trained predictive models using **Scikit-learn**.
   * Evaluated model performance using regression metrics and confusion matrices.

4. **Interactive Power BI Dashboard:**
   * Designed dynamic visuals to communicate pricing trends, feature impacts, and key business insights to stakeholders.

---

##  Repository Structure
* `data/` – Contains raw and cleaned datasets.
* `notebooks/` – Google Colab notebook(s) with full Python code, EDA, and ML models.
* `dashboards/` – Interactive Power BI (`.pbix`) report file.
